# Workspace Rules - AlvaroProfemate Web

## Directiva de Commits y Despliegues en Netlify
- **NO realizar `git commit` ni `git push` de forma automática** al finalizar tareas o cambios en los archivos del proyecto.
- Los cambios deben guardarse localmente en los archivos de la plataforma (`.html`, `.css`, `.js`, etc.).
- Únicamente hacer `git commit` y `git push` cuando el usuario lo solicite explícitamente (ej: "haz commit", "sube los cambios", "actualiza netlify"). Esto permite optimizar el consumo de créditos y compilaciones en Netlify.
